Security & deployment

This is an early frontend prototype. User authentication, tenant isolation, persistent conversation storage, billing, audit logs and production-grade abuse controls are not implemented yet.

Configure AI_BASE_URL, AI_MODEL, AI_API_KEY and CORS_ORIGINS as private environment variables on your backend host. Do not commit secrets to GitHub.
